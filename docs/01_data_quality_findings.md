# Business Task 01 – Data Quality Assessment

## Business Objective
Evaluate the quality of bank transaction data
before using it in financial reporting.

## Dataset Overview
- Total transactions: 60,000
- Period: 2024–2026
- Currencies: CZK, EUR, PLN, USD

## Key Findings

### 1. Missing Categories
- 561 transactions have missing category assignments.
- This represents 0.935% of all transactions.

### 2. Duplicate Transactions
- No duplicate groups were identified using
  account, amount and booking date.

### 3. Zero-Amount Transactions
- No transactions with an amount of zero.

## Business Recommendations
1. Investigate missing transaction categories.
2. Validate transaction data before reporting.
3. Monitor data quality on a regular basis.
